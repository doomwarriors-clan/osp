OSP Tourney DM/CA/CTF 1.03a-dwc
================================

OSP Tourney 1.03a with security fixes and the DoomWarriors bot learning
extension ("botmem"), built from the xq3osp sources:

  https://github.com/doomwarriors-clan/osp
  (fork of https://github.com/JKornev/xq3osp)

xq3osp is reverse-engineered source code of OSP Tourney 1.03a, restored from
the QVMs OSP shipped in 2002 and 2003. The security fixes address
memory-safety and input-validation bugs that a malicious player or server
could use to crash the game, corrupt its memory or run console commands.
The botmem extension lets the bots learn per-map item/goal weights; it is
gated by the bot_memory cvar (off by default) and is a no-op unless the
engine provides the matching botmem syscalls. Gameplay is unchanged.

Files
-----

  zzz-osp-dwcN.pk3     server: vm/qagame.qvm (security fixes + botmem)
                       (overrides the qagame of zz-osp-server*.pk3)

Put it in the osp folder of the server, next to the original OSP pk3s and
the two pk3s of 1.03a-secured (zz-osp-server4.pk3, zz-osp-pak5.pk3):

  https://github.com/JKornev/xq3osp/releases/tag/1.03a-secured

cgame and ui are unchanged and byte-identical to 1.03a-secured, so clients
use its zz-osp-pak5.pk3; there is no client pk3 of our own.
SHA256SUMS.txt in the release lists the hashes of the QVMs and pk3s.
